Keyword Clusters: Group Keywords into Topics That Rank

A practical guide from Keyword Finder.

A keyword cluster is a group of related keywords that belong to one topic, with one main page and several supporting pages. Instead of writing one page per keyword in isolation, you write a set of pages that cover a topic thoroughly and link to each other. Search engines reward this, because a site that covers a topic in depth looks more authoritative than a site with a single page on it. This guide explains how to build a cluster, how to choose the main page, and how to link the pages so they help each other rank.

What a cluster looks like

A cluster has a pillar page that covers the main topic broadly, such as a complete guide to keyword research, and several cluster pages that cover subtopics in depth, such as long-tail keywords, difficulty and intent. Each cluster page targets its own keyword and links back to the pillar page, and the pillar page links to each cluster page. Together they cover the topic from several angles. A reader can start at the pillar page and go deeper, or land on a cluster page and find the broader guide. The structure is useful to readers and clear to search engines.

Build a cluster from your keyword list

Look at your keyword list and group keywords that belong to the same topic. The group should have one broad keyword for the pillar page and several specific keywords for the cluster pages. If a group has only one keyword, it is not a cluster yet; either find more keywords in that topic or treat it as a single page. If a group has too many keywords, split it into two topics. A good cluster has one pillar page and three to ten cluster pages. Write the pillar page first, so you know what it covers, then write the cluster pages to fill the gaps.

Link the cluster together

Linking is what makes a cluster work. Every cluster page should link back to the pillar page with a clear link, and the pillar page should link to every cluster page where it mentions that subtopic. Cluster pages can also link to each other where it is natural, but do not link every page to every other page, because that becomes noise. Use descriptive link text that tells the reader what they will find, not just click here. Good internal links help readers navigate and help search engines understand the relationship between the pages.

Grow and maintain clusters

A cluster is not finished when the pages are published. Add new cluster pages when you find new subtopics, update the pillar page to link to them, and refresh old pages when facts change. Track which clusters bring traffic and which do not. A cluster that brings steady traffic is a topic your site is becoming known for, and it is worth expanding. A cluster that brings nothing may need better pages, better keywords, or a different topic. Review clusters every few months, and keep the ones that work growing.

Quick tips

  • One pillar page plus three to ten cluster pages
  • Group keywords by topic first
  • Link every cluster page back to the pillar
  • Review clusters every few months

Frequently asked questions

What is a keyword cluster?

A group of related keywords around one topic, covered by a broad pillar page and several detailed supporting pages that link to each other.

How many pages should a cluster have?

One pillar page and three to ten cluster pages is a good size. Fewer than three supporting pages is not really a cluster, and too many can be hard to maintain.

Why do clusters help SEO?

They show depth on a topic, help readers navigate, and let pages support each other with internal links, which can help the whole group rank better.
